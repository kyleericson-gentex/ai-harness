# Discovery Phase

## Description

This is the first step in a multi-step process to implement a new feature, fix a bug, etc.
The goal of this phase is to analyze the repository and build a full understanding of the repository and the code.

Make note of anything that would be important to accomplish the objective.


## Tasks

- Understand the repository
- create a new git branch for the feature/fix before making changes. Follow this naming convention 'ai/<feature-name>'
- create .ai/discovery.md file in the repository detailing your findings. This is used as input for future phases
- update/create a standard AGENTS.md file in the project as needed
- commit your changes


## Reminders

- .ai/discovery.md is not a permanent file and should not be referenced to elsewhere in the repo
- AGENTS.md and discovery.md are isolated and should not reference each other
- DO NOT create any files that you were not instructed to create.
- DO NOT suggest implementations.
- DO NOT modify any code.
- DO NOT write any code.


## Phase Complete Checklist
 
- Code has been analyzed and understood
- IF ABLE, new git branch has been created for this new feature/goal
- AGENTS.md file has been created/updated
- .ai/discovery.md is created
