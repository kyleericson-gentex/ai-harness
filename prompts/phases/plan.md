# Planning Phase


## Description

This is the planning phase of a multi-phase process to complete out objective. This phase is for creating a plan
that we will use to create actionable tasks later in the process. Your job is to read the input created by the discovery phase
and use that knowledge to develop the plan.


## Input

- Review the objective
- Review AGENTS.md
- Review .ai/discovery.md


## Tasks

- using the knowledge gained from discovery.md, create a plan for implementing our objective
- create a file: .ai/plan.md that details this plan
- commit your changes


## Reminders

- .ai/plan.md is not a permanent file and should not be referenced to elsewhere in the repo


## Phase Complete Checklist
 
- .ai/plan.md has been created
- changes have been committed
