# Code Implementation Phase

## Description

This is the fourth phase of a multi-phase process with the end goal to implement a solution that completes our objective.
The goal of this phase is to execute the plan outlined in ```.ai/plan.md``` which was then broken down into actionable tasks
in ```.ai/tasks.md```

While you will read through all artifacts left by previous phases, your main focus is on task list found in ```.ai/tasks.md```

You are allowed to edit the code as needed to accomplish our objective according to the plan and tasks provided to you.

## Input

- Review the objective
- Review ```AGENTS.md```
- Review ```.ai/discovery.md```
- Review ```.ai/plan.md```
- Review ```.ai/tasks.md```


## Tasks

- complete each task in ```.ai/tasks.md``` in order
- create commits on your current working branch as you complete tasks
- in each git commit make sure you explain your code changes
- Update ```AGENTS.md``` as needed


## Reminders

- code should be clean and concise
- code should be self documenting, use names that are descriptive and are NOT non-sensical
- comments should be used only when absolutely neccessary to explain something uncommon
- consider coding conventions and knowledge of the entire repo
- be consistent with coding styles and conventions used


## Phase Complete Checklist
 
- each task in ```.ai/tasks.md``` has been completed
- new code is consistent with the repo conventions
- new code is double checked for bugs and errors
- new code has been reviewed for secuirty vulnerabilities
- ```AGENTS.md``` has been updated as needed
- all changes have been committed
